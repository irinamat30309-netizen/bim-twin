## Артефакты экспорта

- Экспортированные E57 перечитаны `E57Core`: по 205 526 точек. E57 из геопривязанного LAS содержит мировые координаты; E57 из локального PLY остаётся в исходной локальной системе.
- Свежие PLY и LAS-классы повторно открыты внутренним парсером: по 205 526 точек.
- DSM/DTM: читаемые Float32 GeoTIFF 14×10, шаг 0.5 м. DSM диапазон около 2.94–3.01 м; DTM около −0.0004–0.0803 м. Это indoor fixture, а не проверка качества terrain-модели.
- Плановый DXF: по 5 LINE-сущностей. IFC2X3: корректный STEP-заголовок/конец и 5 `IFCWALL`.
- Mesh OBJ на PLY: 6 680 вершин и 12 612 граней.
- Контурный DXF корректно содержит 0 сущностей: на комнатном облаке при интервале 0.5 м поверхность не пересекает ни один контурный уровень; terrain-workflow этим не подтверждён.
- В текущем Python runtime не импортируются `pye57` и `laspy`. Поэтому свежие E57/LAS в этом повторном прогоне проверены внутренними читателями и UI round-trip, но не независимым Python reader.

## Блокирующее расхождение реконструкции

`room.las` и `room.ply` — практически один набор соответствующих точек: после жёсткой регистрации найден поворот около 2.000° и RMS около 0.49 мм. Тем не менее:

- Scan→BIM возвращает 4 стены для LAS и 3 стены для PLY;
- независимый путь IFC2X3/планового DXF сообщает 5 стен;
- BIM 1:1 offline наследует результат встроенного движка, а не служит независимым эталоном.

До определения ground truth для стен/перегородок и унификации frame-normalization эти модели **не считаются принятыми**. Это приоритет регрессионного расследования, а не косметическое различие.

## Не проверено / дальнейшие gates

1. Целевая Windows-сборка/ASAR, чистая установка, native dependencies и SQLite (`better-sqlite3` отсутствует, использован JSON fallback).
2. Независимый IFC validator и reopen в Revit/Bonsai/другой целевой BIM-системе.
3. Независимые E57/LAS readers на свежих артефактах; большие облака и out-of-core производительность.
4. Полный семантический acceptance для 39 действий без регистрируемого toast/modal/log.
5. Terrain fixture с известными Z, contour DXF с ожидаемыми уровнями, CRS/datum и контрольной поверхностью.
6. Эталонная разметка помещения, rotation-invariance и единый wall-set для Scan→BIM/IFC/DXF.
7. Паритет с LixelStudio/CoProcess по каждой обязательной строке `MARKET-FEATURE-MATRIX.md`; ручная пользовательская приёмка.
