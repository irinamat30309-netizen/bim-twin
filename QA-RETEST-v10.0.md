# Повторная проверка — review v10.0

## Среда

Локальная Linux-среда, Node.js 24, Playwright + Chromium с программным WebGL/SwiftShader, пользовательские образцы из `/data/BIM-TWIN-user-fixtures-v10.0/`. UI-тест использовал чистый временный профиль fake-Electron harness; это не запуск собранного Windows-инсталлятора.

## Результаты

| Проверка | Результат |
|---|---|
| `BIM_TWIN_USER_FIXTURES=/data/BIM-TWIN-user-fixtures-v10.0 node --test` | 727 тестов: 724 прошли, 3 пропущены, 0 ошибок; пропуски — LAZ-путь без доступного декодера |
| Синтаксис JS/MJS/CJS | 227 файлов проверены через `node --check`, 0 ошибок |
| `node db/_test.js` | `ALL PHASE D TESTS PASSED`, `ALL PERSISTENCE TESTS PASSED` |
| UI OBJ | Worker; 315 390 треугольников; 809 574 render-вершин; 1 mesh primitive; экран и предупреждения проверены |
| UI STL | Worker; 315 495 треугольников; 946 485 render-вершин; 1 mesh primitive; экран и предупреждения проверены |

Последний чистый OBJ-прогон занял около 9,6 с, STL — около 4,4 с от выбора файла до завершения UI; в соседних прогонах было 8,9–9,6 с и 4,4–5,7 с соответственно. Время включает чтение/сохранение через fake-Electron JSON fallback и рендер SwiftShader; это разброс тестовых запусков, а не производительный benchmark.

Оба UI-сценария завершились без page/console/IPC ошибок. В runtime-log зафиксирован Worker для каждого файла; метка версии `1.1.17 · review v10.0` и левая панель инструментов видны поверх mesh-viewer, а hit-test центра первой кнопки подтверждает, что mesh canvas её не блокирует. При старом слое `z-index:40` mesh canvas перекрывал эти элементы; после изменения слоя кадры и E2E-проверка подтверждают исправление.

## Геометрические проверки

- Пользовательский OBJ: 249 260 исходных граней; результат импорта 315 390 треугольников. 105 вырожденных/повторных углов исключены и показаны в сообщении; MTL/группы/CRS/единицы обозначены как неподдерживаемые/неизвестные.
- Пользовательский STL: declared facets и результат совпадают — 315 495; бинарный размер файла согласуется с заголовком и payload.
- Section kernel на обоих пользовательских мешах дал 488 замкнутых и 135 открытых контуров. Открытые контуры сохраняются как открытые: исходники не объявляются watertight solids. Отдельный unit-тест замкнутого синтетического куба проверяет closed polyline и R12 DXF entity.
- Цветной бинарный PLY на 15 352 950 точек прошёл Node-стример с лимитом 1 000 000; получено 959 559 точек после воспроизводимой выборки. Полный браузерный рендер 15,35 млн точек, память GPU/RAM и стресс-тест не выполнялись.
- DWG образец проверен только на идентификацию формата/версии AC1021; RVT/RFA/SKP были инвентаризированы, но нативное чтение/рендер этих форматов не подтверждено.

## Ограничения и воспроизводимость

- В тестовой среде нет `better-sqlite3`; приложение использовало JSON-store fallback. Персистентность fallback проверена, runtime SQLite этим прогоном не подтверждён.
- LAZ-путь, Windows installer/ASAR, GPU на целевом ПК и открытие в сторонних CAD/BIM/GIS не тестировались.
- У OBJ не поддержаны MTL/текстуры/групповая иерархия. CRS, units и up-axis не выдумываются. DWG/Revit/SketchUp остаются неподтверждёнными.
- Условия пользовательских исходников и право на распространение не установлены. В архиве есть только `QA-artifacts/v10.0/fixture-manifest.json`, без самих моделей.
- Полный долгосрочный план продолжает этапы 1–14; результат v10.0 не является заявлением о 100% готовности рынка.

E2E-снимки, JSON-сводка, manifest и сырые логи тестов лежат в `QA-artifacts/v10.0/`.
