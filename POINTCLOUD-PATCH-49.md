# POINTCLOUD-PATCH-49 (v1018) — Фикс «кубиков» после авто-очистки

## Симптом
После «Авто-очистки» точки превращались в большие квадраты, качество падало.

## Причина
1. При ПЕРВОЙ загрузке loadCloud точно оценивает шаг между точками
   (~13.5 мм) по соседям в порядке сканирования, ЗАТЕМ перемешивает массив
   (shuffle) для больших облаков (>2М).
2. Авто-очистка читает УЖЕ перемешанный массив, чистит и перезагружает.
3. При перезагрузке _estimateSpacing берёт 9000 ПОДРЯД точек — но они
   теперь разбросаны по всей сцене (200 м) → шаг оценивается в метры вместо мм
   → размер точки раздувается → большие квадраты.

## Исправление (renderer/webgl-viewer.js)
- loadCloud теперь уважает явный cloud.spacing: если передан — берёт его
  вместо оценки по соседям.
- Все перезагрузки после правки/чистки (deleteSelection, cropToSelection,
  undoEdit, cleanInApp, cleanClustersInApp) передают уже известный bo._spacing.
  Плотность в оставшихся зонах не меняется, поэтому шаг корректен.
