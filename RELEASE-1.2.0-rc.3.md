# BIM Twin 1.2.0-rc.3 — переработанный интерфейс

Дата: 2026-09-30. Ветка: `agent/ui-redesign` (включает `agent/finalization` = `1.2.0-rc.2`).

## Решение

`1.2.0-rc.3` меняет только слой интерфейса: раскладку, иконки, меню, диалоги, анимации и стартовый экран. Основной
процесс (`main.js`, `preload.js`), хранилища (`db/*`), безопасность (`security/*`) и IPC-контракт не менялись, форматы
данных остаются прежними. Документация дизайн-системы — `UI-DESIGN.md`, стенд проверки — `dev/ui-lab/README.md`.

## Что изменилось для пользователя

**Порядок команд.** Разрозненные ряды кнопок заменены лентой из 11 вкладок: Проект · Импорт · Облако · Этажи · Измерения ·
Чертёж · BIM · Вид · 3D-тур · Контроль · Экспорт. Каждая из 115 команд стоит в одной вкладке и в группе по смыслу
(например, «Измерить объект» — «Измерения → Объект», «Горизонтали» — «Облако → Рельеф и грунт»). Команды, которым нужно
облако, неактивны, пока оно не загружено. Лента прокручивается со стрелками и сворачивается; последняя вкладка и состояние
панелей запоминаются. Все команды доступны через палитру (`Ctrl K`).

**Иконки и оформление.** Один линейный набор (Lucide, 187 иконок) вместо смеси эмодзи и символов; иконка + подпись в
крупных кнопках, компактные кнопки в группах; единые токены цвета/радиусов/теней, тёмная и светлая темы; шрифт Inter вшит в
приложение (работает офлайн).

**Меню и диалоги внутри функций.** Всплывающие меню (очистка, геометрия, «Ещё», контекстные) выезжают от кнопки, не выходят
за край окна и управляются с клавиатуры. Окно «Инспектор объекта» (после выбора рамкой в «Измерить объект») перестроено:
режимы отображения и виды — на сцене, инструменты замера, результат и история — справа; закрывается крестиком, `Esc` или
щелчком по затемнению. Панели «Измерение», «Правка облака» и «Станции» собраны в общий нижний док без наложений; плавающие
панели сворачиваются.

**Загрузка и движение.** Сплэш рабочей области, тонкая полоса прогресса для фоновых операций, спиннер на кнопках,
скелетоны вместо пустых списков, стопка тостов с полоской времени, плавное появление панелей и меню (120–280 мс;
отключается при `prefers-reduced-motion`).

**Стартовый экран.** Карточки проектов (выбор мышью и клавиатурой), поиск при пяти и более проектах, «Новый проект» с
проверкой ввода, состояния «загрузка», «пусто» и «ошибка + Повторить», настройки (тема, хранилище, версия), плавный переход
в рабочую область.

**Встроенные диалоги вместо нативных.** В Electron `prompt()` не работает, а `confirm()` выглядит чужеродно. Все вызовы
`prompt/confirm/alert` заменены на `__lxKit.ask` (в том числе «Текст» на чертеже, «Ресэмплинг», «Горизонтали», «Геопривязка»,
класс LAS, координаты DXF, наборы сечений). Тест `test/ui-dialogs.test.js` следит, чтобы нативные вызовы не вернулись.

**Исправленные дефекты.** Повторный клик по «Измерить объект» после выбора рамкой снова запускает выбор; `Esc` останавливает
выбор и закрывает окно инспектора; кнопки «Выйти» в панелях измерения, правки и станций подключены; «мёртвые» тосты
меш- и сплэт-вьюеров работают; кнопка 3D-тура восстановлена; удалены дубли и заглушки (`tsSplat`, `mlCsv`, `mlNotion` и др.);
спиннер на цветных кнопках виден; страница не «съезжает» вбок при 1024 px.

## Что удалено

18 файлов прежнего интерфейса (`lixel-ribbon.*`, `lixel-shell.*`, `lixel-toolbar.js`, `lixel-tool-dock.js`, `lixel-ui.*`,
`lixel-ui-refresh.css`, `lixel-polish.css`, `lixel-menu-unify.css`, `lixel-cloud-ui.css`, `lixel-draw.css`,
`lixel-workspace.css`, `ui-v1208.*`, `ui-v1213.*`) и 6 тестов, проверявших их внутренности. Их заменяют `renderer/ui/*` и тесты
`ui-system`, `ui-commands`, `ui-modes-behavior`, `ui-dialogs`, `ui-startup`.

## Ограничения (честно)

* Интерфейс проверялся в Chromium со SwiftShader и заглушкой IPC (`dev/ui-lab`). Реальный Electron на Windows с GPU,
  файловые диалоги ОС, окно без рамки и подсказки ОС не запускались в этой среде — нужна приёмка на целевой машине.
* Установщик `.exe` собирается только в GitHub Actions (`windows-package-qa`, артефакт `windows-package-qa`); в Linux-среде его нет.
* Новые подписи (лента, диалоги, стартовый экран) только на русском: переключатель языка их не переводит.
* Тесты интерфейса в основном source-level и на `vm` (без браузера); поведение проверяется стендом, который в CI не запускается.
* Крупные облака в стенде рисуются программно (SwiftShader), поэтому частота кадров и время загрузки в нём не показательны.

## Воспроизведение

```bash
npm ci
npm test                                   # 987 тестов
node scripts/check-syntax.mjs
node tools/build-ui-icons.mjs --check      # иконки
node tools/build-ui-fonts.mjs --check      # шрифт
# визуальный стенд (нужен Chromium): см. dev/ui-lab/README.md
node dev/ui-lab/server.js & cd dev/ui-lab && node panels.js 1440 900 dark
```

Сборка Windows-пакета — `BUILD-WINDOWS.md`.
