# Обновления баз ИИ-ассистента BIM Twin

Программа раз в сутки (настройка «Опыт и знания» → «Обновления баз») читает `feed.json` из этой папки ветки
`agent/ui-redesign` репозитория и ставит новые выпуски сама. Скачиваются только данные JSON, без кода; каждый файл
сверяется по SHA-256 из ленты, текст проходит фильтр «инструкций для модели».

Типы файлов (поле `format`):
- `bim-twin-norms` — записи базы норм `{docs, entries:[{id, doc, clause, topic, text, tags}]}`; запись с тем же `id`
  заменяет встроенную (так приходят новые редакции);
- `bim-twin-kb` — статьи справки `{articles:[{id, title, tags, text}]}`;
- `bim-twin-knowledge` — пакет знаний и навыков (как «Экспорт пакета» в программе);
- `bim-twin-norms-status` — актуальность документов `{docs:[{code, status, replacedBy}]}`;
- `bim-twin-model` — рекомендуемая базовая модель (сама модель ставится только по кнопке).

Выпуск: положите или измените файл, задайте в нём `release` (версию) и выполните `node ai/knowledge-update.js build knowledge`
— `feed.json` пересоберётся с новыми контрольными суммами. Затем закоммитьте папку.
