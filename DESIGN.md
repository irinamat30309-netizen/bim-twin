# DESIGN.md — BIM Twin

Direction: **graphite industrial, violet accent**. Профессиональный BIM/облачный инструмент для инженеров на объекте: плотная рабочая среда, данные и координаты важнее декора. Дизайн спокойный и предсказуемый; лента/вкладки/панели — рабочие зоны, акцент — только в ключевом действии.

## Identity

- Характер: инженерный, собранный, «приборная панель», не лендинг и не развлекательный продукт.
- Один акцент violet — намеренный жест в ключевом действии и активной вкладке; всё остальное — графит и нейтральные границы.
- Текстуры/фоны без декоративных сеток, бликов, glow и градиентов. Разделение — линии `--line` / `--line-strong`.

## Dials

`ENERGY 1 / RHYTHM 2 / MOTION 1`

- **ENERGY 1**: спокойный интерфейс, никаких кричащих заливок и «AI-стиля».
- **RHYTHM 2**: одинаковые рабочие зоны (лента, вкладки, панели), но акценты в ключевых местах (primary-действие, выбранная вкладка, статус).
- **MOTION 1**: только hover/focus/переходы 120–180 мс; при `prefers-reduced-motion` — выключаются. Никаких fade-up/floating/scale-анимаций страницы.

## Palette

База — нейтральный графит (тёмная тема по умолчанию как у инженерных инструментов: облако и координаты на тёмном фоне), светлая тема — тёплый нейтральный. Один акцент — violet.

| token | dark | light | роль |
|---|---|---|---|
| `--bg-0` | `#1b1a19` | `#efede6` | фон окна |
| `--bg-1` | `#232221` | `#fbfaf7` | лента/панели |
| `--bg-2` | `#272624` | `#f7f5ef` | поля/вторичные поверхности |
| `--bg-3` | `#302f2c` | `#e8e5db` | hover/нажатые |
| `--txt` | `#eeede9` | `#1e1d1b` | основной текст |
| `--txt-2` | `#b9b6ad` | `#4f4d48` | вторичный (AA ≥ 4.5:1) |
| `--txt-3` | `#a3a098` | `#5f5d57` | третичный (AA на своих фонах) |
| `--accent` | `#a78bfa` | `#6d56d1` | единственный акцент (light-вариант темнее для контраста) |
| `--accent-soft` | rgba(167,139,250,.12) | rgba(109,86,209,.10) | подложка primary-иконки/выбранного |

Правило: акцент используется **один раз** на экран как primary-действие (главная кнопка диалога/«Построить BIM») и в активной вкладке (2px underline). Второстепенные кнопки нейтральные, violet появляется на hover-границе и focus-ring.

## Typography

Один гуманистический sans (`Inter Variable` + системные fallback) для интерфейса; моноширинный не используется как «терминальная» эстетика — только для кода/координат.

Шкала: **11 / 12 / 13 / 14 / 16 / 20 / 24**. Основной текст 13–14 px, заголовки 16/20/24, подписи 11–12. Вес 400/500/600. Interline: 1.2 для заголовков, 1.45 для текста.

- Без UPPERCASE+широкого трекинга; подписи секций — 11–12 px, weight 600, обычный регистр.
- Числа, координаты, счётчики, VRAM, FPS — **tabular nums** (`font-variant-numeric: tabular-nums`).
- Вторичный текст поднят до WCAG AA (≥4.5:1) в обеих темах; третичный проверяется на своих фонах.

## Radius & spacing

- Radius scale: **4 / 6 / 8** (`--r-1 4`, `--r-2 6`, `--r-3 8`). Pill (999) — только статус-чипы и переключатели, где форма функциональна.
- Сетка 8 px: паддинги 8/16, между группами 8, радиус не «съедает» плотность.
- Кнопки: 32 px (sm 28, xs 24); иконки 16/20/28.

## Elevation

- Тени только у приподнятых слоёв: меню, поповеры, диалоги, HUD, тосты.
- Панели, лента, вкладки, карточки — **границы** (`--line`/`--line-strong`), без теней.

## Icons

Один набор (`renderer/icons.js`), иконки по смыслу действия; размеры 16 (в тексте), 20 (панели), 28 (лента). Без sparkle/star/magic/robot/orb и без дублирования иконки эмодзи.

## States & interaction

- Hover: фон `--bg-3` + граница; active: 1px сдвиг/затемнение; disabled: opacity .45 + `not-allowed`; focus-visible: 2px accent ring с offset 2.
- Все элементы с действием — `<button>`/`<a href>`; клавиатура Tab/Enter/Esc; панели имеют empty/loading/error состояния.
- `prefers-reduced-motion: reduce` отключает анимации и переходы.

## Governance

- Это направление обязано сохраняться в r130/r178/r191: доп. панели не включаются старым флагом, рендер/облако не меняются.
- Любое новое визуальное решение должно иметь одну строку обоснования (R-31) и не превышать ограничения палитры (2–3 core + 1 accent).
