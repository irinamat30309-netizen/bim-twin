# BIM TWIN — повторная проверка Stage 2

## Объём

Проверялись сохранение/восстановление состояния проекта и облака, журнал операций, undo/redo, миграции, целостность snapshot, rollback, переключение проектов и повторный запуск приложения. Пользовательские крупные BIM/point-cloud архивы и функциональность следующих этапов в этот прогон не входили.

В UI-прогоне первоначальный snapshot содержал 205 526 точек. Для проверки версий был сохранён вариант на одну точку меньше, затем выбран и восстановлен первоначальный snapshot. Проверено, что history по-прежнему содержит обе ревизии, а в журнале сохранены SHA-256 входа/выхода, параметры, timestamp, предупреждения и версия приложения.

В последнем полном прогоне пропущены два теста пользовательских больших OBJ/STL/PLY fixtures, потому что `BIM_TWIN_USER_FIXTURES` не был задан. В этой же сессии PLY из пользовательского набора отдельно разобран и проверен как потоковый импорт; он описан в `QA-RETEST-stage3.md`. Это не превращает OBJ/STL fixture-тесты в пройденные.

Ранее отмеченные LAZ-пропуски сняты только для этого прогона: тесты запускались с временным optional `@loaders.gl/las` 4.5.2 вне репозитория; Stage 3 отдельно фиксирует, что без этого decoder LAZ не доступен.

## Ограничения испытательной среды

- E2E запускает renderer в Chromium и перехватывает Electron IPC; это не упакованное настольное приложение. Для SQLite-path временно использовался настоящий native driver `better-sqlite3` 11.10.0, установленный вне проекта; файлы драйвера в проект/архив не включались.
- SQLite migration suite использует адаптер API поверх встроенного `node:sqlite`; E2E с настоящим native driver отдельно проверил путь приложения через `SqliteStore`.
- Повторная проверка выполнила реальный Linux DAC denial через `setpriv` и read-only каталог. Это не проверяет Windows ACL и права упакованного приложения.
- Идемпотентность проверена для повторного сохранения одного и того же нормализованного состояния и целостности неизменяемых файлов. Это не доказывает битовую идентичность результатов всех алгоритмов обработки облаков.
- Полный Windows/macOS installer, аппаратный crash/power loss, восстановление после дискового сбоя и нагрузка на размерах, превышающих тестовую fixture, не проверялись.
