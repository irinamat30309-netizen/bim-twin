# POINTCLOUD-PATCH-46 (v1015) — Лучшая чистилка облака: шум + отсоединённые кластеры

## Проблема (со слов пользователя)
- Авто-чистка 🧹 убирала только шум, но НЕ лишние «облака точек по типу людей» / мусор.
- Причина найдена: воксель фильтра плотности по умолчанию считался от диагонали сцены
  (`diag*0.005` ≈ 1.4 м при габаритах ~200×57×199 м) — в таком огромном вокселе почти
  всегда >8 точек, поэтому удалялось ~29k из 52M (≈ ничего).

## Что сделано
1. **renderer/pointcloud-edit.js** — новая функция `cleanClusters(cloud, opts)`:
   Euclidean clustering по 26-связности занятых вокселей (типизированные массивы, BFS,
   грид ограничен ≤3e7 ячеек). Главная связная структура (стены/пол/потолок) сохраняется,
   мелкие ОТСОЕДИНЁННЫЕ кластеры (летающий мусор, «снег», обособленные объекты) удаляются.
   Возвращает `{pos,col,removed,removedPos,removedCol,clusters}`. Добавлена в API export.
2. **renderer/webgl-viewer.js**:
   - `cleanInApp` теперь берёт воксель от РЕАЛЬНОГО шага облака (`bo._spacing * voxelFactor`,
     по умолчанию ×3 ≈ 4 см) вместо диагонали → фильтр плотности реально работает.
   - Новый метод `cleanClustersInApp(opts)` (воксель связности = `_spacing * connect`, ×4),
     тот же компактный undo (хранит только удалённые точки) + перезагрузка облака.
3. **renderer/app.js** — кнопка 🧹 теперь двухэтапная и с эскалацией:
   шум (`minPts` 6→9→12…) + отсоединённые кластеры (`minClusterPts` 120→240→480…).
   Каждое нажатие сильнее. Тост честно поясняет: люди/мебель НА ПОЛУ связаны со
   структурой и удаляются вручную — «Правка» → лассо → 🗑.

## Честное ограничение
Полностью автоматически «вырезать людей», стоящих на полу, нельзя без ML-сегментации
(PointNet/KPConv), которая не запускается офлайн в приложении. Надёжный способ для
таких объектов — ручное лассо «насквозь» (v1014), теперь работает корректно.
