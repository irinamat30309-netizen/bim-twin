# POINTCLOUD-PATCH-42 (v1008) — исправление 5 багов по отчёту из консоли действий

Сборка v1007 снова запускалась (краш v1006 c Proxy устранён). По логам консоли действий
исправлены 5 замечаний.

## 1. Прогулка проваливалась под пол
`webgl-viewer.js setWalk()` брал высоту глаз от `bbox.mn[1]` (абсолютный минимум Y).
В сканах под полом почти всегда есть точки-выбросы, поэтому минимум был на несколько
метров ниже реального пола → камера стартовала под моделью.
**Фикс:** добавлен `_robustFloorY()` — 5-й перцентиль Y по выборке точек облака
(устойчив к выбросам). Высота глаз теперь = робастный пол + 1.2…1.7 м.

## 2. Убрана «Экскурсия» (RealView)
Кнопка `#vtTour` удалена из плавающей панели (`index.html`). Прогулка (WASD) работает
по облаку точек. Код RealView оставлен в движке, но из UI недоступен.

## 3. Редактирование облака
- **Выделение оставалось после выключения режима.** `setEditSelect(false)` теперь
  вызывает `clearSelection()` — красная подсветка и счётчик сбрасываются при выходе.
- Захват «насквозь» (пол за стеной) на очень больших облаках (LOD) остаётся сложным:
  по умолчанию режим «Видимые: точно» (передняя поверхность) + кластеризация фронта.
  Точная настройка глубины — следующим шагом (нужны замечания пользователя).

## 4. Кнопка «Потоковый с диска» (☁) не загоралась
Для облаков ≤64 млн стриминг не нужен (всё влезает в память), и кнопка снималась с
«вкл» → визуально не реагировала. **Фикс:** ☁ сделана нормальным тумблером —
загорается оранжевым в режиме «все точки» и гаснет при повторном клике. Реальный
octtree-стриминг с диска включается только для >64 млн точек (нужен .las).

## 5. Очистка облака
- **Камера сбрасывалась на исходный вид.** Перечитывание облака после очистки
  (и после операций геометрии, и после стриминга) шло без `preserveView` → `_frame()`
  переставлял камеру. **Фикс:** `loadCloud(pr, { preserveView: true })` — вид сохраняется.
- **«Ничего не менялось» (удалялось ~1000 точек из 51 млн).** Порог был слишком мягкий
  (`denoise minPts:6`, авто-воксель ×3). Усилено до `minPts:8, factor:2.2` (воксель ×2.2) —
  заметно больше шума/флоатеров. При необходимости силу можно ещё поднять/опустить.
  Примечание: без Open3D работает NumPy-путь (медленно, ~2–3 мин на 51 млн). С Open3D
  (Python 3.9–3.12) очистка на порядок быстрее и качественнее (statistical + radius + HPR).
