# POINTCLOUD-PATCH-52 (v1021) — Лассо удаляет весь объект (не остаётся точек)

## Симптом
Ручное лассо выделяло объект правильно, но после удаления
оставались точки — удалялась лишь передняя «корка».

## Причина
Режим 0 «Только объект» брал только GPU-видимые точки (переднюю
поверхность). Задняя/внутренняя часть объекта (перекрытая) не попадала
в выбор, поэтому оставалась после удаления.

## Исправление (renderer/webgl-viewer.js)
Режим 0 теперь берёт ВЕСЬ ближний объект: от передней видимой
поверхности назад по глубине до ПЕРВОГО разрыва (перед стеной сзади).
- Пороги в АБСОЛЮТНЫХ метрах от шага скана (не от габаритов сцены):
  разрыв gap = max(шаг*8, 0.2м), макс. глубина band = max(шаг*60, 1.2м).
- clusterFront получил bandOverride, чтобы не отбрасывать заднюю часть
  объекта в пределах выбранной глубины.
Стена/пол за разрывом не затрагиваются.
