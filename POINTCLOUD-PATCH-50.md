# POINTCLOUD-PATCH-50 (v1019) — Лассо удаляет только объект, а не насквозь

## Симптом
Ручное удаление било «лучом» (насквозь): обводишь объект — удаляется весь
столб по глубине (стена/пол за ним тоже). При повороте камеры (ПКМ) видно,
что красное выделение — это луч насквозь, а не сам объект.

## Причина
Режим глубины выделения по умолчанию был = 2 (насквозь) и в setEditSelect,
и в обработчике кнопки редактирования. Поэтому любое лассо било по
всей глубине. Режим 0 (только видимая поверхность + очистка фона) уже
был реализован, но не включался по умолчанию.

## Исправление
- Дефолт теперь = режим 0 «Только объект»: удаляется лишь видимая
  поверхность обведённого объекта (передний кластер), без точек за ним.
  Красным подсвечивается только объект — луча больше нет.
- Кнопка в панели редактирования по умолчанию: «Только объект» (выкл).
  При нажатии переключается в «Насквозь» — для летающего мусора в воздухе.

## Файлы
- renderer/webgl-viewer.js: setEditSelect -> _selDepthMode=0, _selThrough=false.
- renderer/app.js: вход в режим → setSelectDepthMode(0); let selDepthMode=0;
  метки кнопки «Только объект».
- renderer/index.html: edThrough без класса on (выкл по умолчанию).
