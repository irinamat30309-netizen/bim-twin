# POINTCLOUD-PATCH-57 - Navigation & UX fixes

## Changes
1. **Максимальное приближение колёсиком** - минимальная дистанция камеры снижена 0.03 -> 0.003 (в `wheel` и `zoomBy`), ближняя плоскость отсечения снижена 0.01 -> 0.001, чтобы можно было подлететь вплотную без клиппинга.
2. **Орбита 360 в режиме удаления** - в режиме редактирования облака правая кнопка мыши теперь вращает камеру вокруг объекта (orbit), а не панорамирует. Левая кнопка = выделение, ПКМ = орбита, колёсико = зум. (Раньше ПКМ давала только pan: верх/низ/лево/право.)
3. **Убран «потоковый octree с диска»** - кнопка ☁ (vtStream) удалена из панели инструментов, т.к. вызывала сбои. Обработчик защищён `if (sb)`, поэтому удаление кнопки безопасно; логика стриминга в коде оставлена, но недоступна из UI.

## Files changed
- `renderer/webgl-viewer.js` - zoom clamp, near plane, RMB orbit in edit mode.
- `renderer/index.html` - удалена кнопка vtStream; версия ассетов 1025 -> 1026.
