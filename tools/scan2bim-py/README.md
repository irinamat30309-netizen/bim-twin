# Новый стек scan-to-BIM на Open3D + IfcOpenShell

Ревизия 90. Решение перейти с самописной эвристики на проверенные библиотеки:

- **open3d 0.20.0** — RANSAC-плоскости, нормали, воксели, кластеризация.
- **ifcopenshell 0.9.0.post1** — сборка валидного IFC4 (стены, проёмы, плиты, помещения, стили).
- **shapely 2.2.0** — полигоны помещений (minimal rotated rectangle, булевы операции).

## Что уже проверено (прототип 1)

	ools/scan2bim-py/proto-open3d.py на вашем интерьере (3,13 млн точек, локальный кадр):

- 60 плоскостей RANSAC, из них 29 вертикальных и 31 горизонтальная;
- 20 стен после слияния, суммарная длина 212 м;
- сетка здания 4,62° (в старой модели 4,3° — совпадает в пределах точности);
- цвета стен берутся как средний RGB инлайеров плоскости (0,49/0,42/0,40 и т.д.).

Ограничение прототипа: каждая RANSAC-плоскость — одна грань стены, поэтому толщина 0,06 м.
Следующий шаг — спаривать параллельные плоскости с противоположными нормалями в стену, как в текущем
движке, но на надёжных RANSAC-плоскостях.

## Почему не берём готовое целиком

Проверенные открытые проекты:

- [pointcloud2ifc](https://github.com/rsasaki0109/pointcloud2ifc) (MIT) — Open3D + IfcOpenShell, но геометрия
  каждого сегмента = bounding box, то есть «коробки», а не стены с проёмами;
- [IfcOpenShell](https://github.com/IfcOpenShell/IfcOpenShell) — только запись/чтение IFC, геометрию не строит;
- [Bonsai (BlenderBIM)](https://bonsai.bim/) — ручное моделирование поверх облака, не автоматика;
- [CloudCompare](https://www.cloudcompare.org/) — обработка облака, не BIM;
- исследования: [Open-source automatic pipeline … to IFC](https://www.sciencedirect.com/science/article/pii/S0926580525003437),
  [Semantics-Guided Reconstruction of Weak-Manhattan Indoor as-Built BIMs](https://ieeexplore.ieee.org/document/11513908),
  [A-Scan2BIM](https://huggingface.co/buckets/huggingchat/papers-content/tree/2311/2311.18166.md) — код либо не публичен,
  либо требует обучения на своих данных.

Вывод: полностью автоматического open-source решения «1:1» нет; у всех пайплайнов есть ручная доводка.
Поэтому берём лучшую связку библиотек (Open3D + IfcOpenShell) и наш движок переводим на неё, а для 1:1
добавляем режим полуавтомата: правка стен/проёмов в приложении с привязкой к облаку.
