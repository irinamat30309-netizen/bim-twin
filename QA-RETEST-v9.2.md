# BIM TWIN — QA повторный прогон v9.2

**Дата:** 2026-09-24  
**Среда:** Linux, Node.js 24.14.1, Chromium через локальный Electron-mock harness; это не установленная Windows-сборка.  
**Статус программы:** из 15 этапов закрыт этап 0; этап 1 частичный; этапы 2–14 не завершены.

## Изменение в этом цикле

В `renderer/scan2bim.js` исправлено сопоставление двух параллельных граней стены. Ранее алгоритм сравнивал абсолютные signed offsets относительно глобального нуля и мог принять две разные, симметричные стены за противоположные грани одной стены. Теперь используется расстояние между центрами линий по нормали первой линии, что не зависит от выбора начала координат.

Добавлен `test/scan2bim-wall-pairing-v1219.test.js`:

- центрированная комната с 4 внешними стенами сохраняет их при 2° наклоне и переносе начала координат;
- сцена с 4 внешними стенами, перегородкой и дверью сохраняет 5 стен и 1 проём при 2° наклоне.

Широкий click-smoke на 97 действий для каждого LAS/PLY проходил ранее в v9.1 с 0 JS/page errors и 12 download-событиями на прогон. После изменения wall-pairing этот широкий sweep не повторялся; вместо этого повторены semantic smoke и реальные UI build-сценарии Scan→BIM/BIM 1:1.

## Остаточные расхождения и ограничения

- Отдельный IFC2X3/плановый путь до фикса сообщал 5 стен на тех же fixtures, тогда как Scan→BIM теперь стабильно сообщает 4. Его пятая плоскость пока не сопоставлена с утверждённой ground truth. Не дорисовывать и не удалять её автоматически до разметки/проверки специалистом.
- Параметры выходов LAS/PLY близки, но не идентичны: площадь пола отличается примерно на 0.29 м²; требуется tolerance/golden-model acceptance на размеченном файле.
- `node --test` содержит 3 skipped; причины не расширялись в рамках этого исправления.
- Широкие 97-кнопочные действия без toast/modal/log (39 на формат в предыдущем прогоне) требуют отдельных assertions. Защищённые 3DGS/тур, очистка и LCC2 не проходили специализированные workflow с реальными входами.
- Windows installer/ASAR, чистая установка и SQLite backend не проверены; в harness использовался JSON fallback.
- В текущем Python runtime не импортировались `pye57`/`laspy`. Свежие артефакты из предыдущего цикла не валидировались независимыми Python readers в этом постфиксном прогоне.
- Версии требуют сверки: `package.json` — 1.1.17; renderer fallback — 0.9.39; toolbar status — 0.9.39 · v1090.
- Полная матрица соответствия LixelStudio/CHCNAV CoProcess остаётся незакрытой; этот фикс — один ограниченный acceptance gate, а не завершение оставшихся этапов.
