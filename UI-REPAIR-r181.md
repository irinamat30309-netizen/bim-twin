## 2. Загрузка сохранённого проекта, где раньше был «false»

В текущем профиле `store.json` найдено **26** сущностей чертежа с `"text": "false"` (наследие старого бага), в т.ч. активный чертёж:
```json
{"type":"text","layer":"TEXT","p":[0,0,0],"h":0.3,"text":"false"}
```
Проверка при старте с этим проектом: `falseEls: []` — санитизация в `lixel-draw.js` (`safeDimText`) применяется **при восстановлении чертежа из проекта** и при отрисовке, поэтому овальная надпись не появляется.

Дополнительно усилено (r181): если при загрузке проекта обнаружен мусор в подписях (`false/true/undefined/null/NaN`), сессия помечается `__sanitized` и **очищенный чертёж перезаписывается** в проекте (`scheduleDrawingSave`), чтобы «false» не возвращался из истории/архива и не зависел от версии сборки. Причина самой записи — старые сохранённые/импортированные сущности `Draw2D` с `text:false`; источник исправлен в r178 (`safeDimText` + `safeTextOut` при экспорте), r181 закрывает сохранённые проекты.
