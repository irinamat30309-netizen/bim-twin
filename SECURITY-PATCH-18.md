# BIM Twin — патч безопасности и надёжности (patched18)

Применено поверх 0.9.39-patched17. Только точечные, низкорисковые правки «быстрых побед» из аудита.

## Безопасность
1. **Content-Security-Policy.** В `renderer/index.html` добавлен строгий CSP:
   `default-src 'self'; script-src 'self' 'unsafe-eval'; style-src 'self' 'unsafe-inline'; img-src 'self' data: blob:; connect-src 'self'; worker-src 'self' blob:; object-src 'none'; base-uri 'self'; form-action 'none'`.
   Блокирует внедрение внешних и inline-скриптов (главный вектор XSS через innerHTML). `unsafe-eval` оставлен для vendor-бандлов (pdf.js и др.); при необходимости можно ужесточить после проверки просмотрщиков документов.
2. **Удалены inline-обработчики `onerror="this.remove()"`** (9 шт.) — несовместимы со строгим CSP; отсутствующие опциональные бандлы и так безопасно обрабатываются проверками `if (window.X)`.
3. **Полное экранирование в `esc()`** (`renderer/app.js`) — добавлено экранирование одинарной кавычки `'` (`&#39;`) к уже имеющимся `& < > "`.
4. **Отключён `plugins: true`** в `webPreferences` (`main.js`) — лишняя поверхность атаки.
5. **Блокировка новых окон и внешней навигации** (`main.js`): `setWindowOpenHandler` + `will-navigate` — внешние ссылки открываются в системном браузере, внутренняя навигация запрещена.

## Надёжность
6. **Атомарная запись `store.json`** (`db/jsonStore.js`) — запись во временный файл + `rename`, чтобы краш в момент сохранения не повредил всю базу JSON-хранилища.
7. **Транзакции для удаления** (`db/sqliteStore.js`) — `deleteRoom` и `deleteFloor` обёрнуты в `db.transaction(...)`; каскадное удаление элементов/находок/документов/версий теперь атомарно (нет «осиротевших» строк при сбое).

- Вынос синхронного IFC-парсинга в worker.
- Хранение LLM-ключа в `safeStorage`.
