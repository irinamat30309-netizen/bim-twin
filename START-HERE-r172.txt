BIM Twin — ФИНАЛЬНЫЙ ПРОЕКТ r172
==================================
ЗАПУСК: cd bim-twin; npm install (один раз); npm start
Модель: deliverables/py2-final-v5.json + py2-final-v5.ifc (A 8/8, 0 ERROR, PSet_BimTwin/UTF-8).
Тесты: node --test (см. финальный прогон), Python 188 проверок PASS, IFC OK.

НОВОЕ В r172 — рендер больших облаков (589.9M / 401.7M) и детализация:
- Размер точки по умолчанию — адаптивный 2–3 px (база 2.8 px, клэмп 2–4 px), в движении не мельче 2 px;
  слайдер точки — множитель (1.0), «жирных» 3–4 px и старых настроек больше нет (миграция bim.perfRev=172).
- Базовый тон без пересвета: gain ×1.1, grade OFF (exposure 1.0/contrast 1.05/saturation 1.05/tone 0.9);
  пресет «Как в Lixel» (1.36/1.29) остался кнопкой в панели «Производительность».
- Качество в движении: динамическое разрешение не ниже 85 % (было 75 % → «мыло»), в авто-режиме рисуется
  65 % точек (было 40 %), в «Быстром» 60 %, «Высокое» — 100 %; в покое качество 1:1.
- WebGL: preserveDrawingBuffer:false, antialias:false, desynchronized:true — основной прирост FPS.
- Бюджет GPU: GPU_POINT_BUDGET 96M (~1,44 ГБ VRAM) для чтения/отображения, LOD-рисование — до 300M
  точек/кадр (Lixel-паритет: hit 0.589 > 0.565 у Lixel); «Показать все точки» — явный флаг.
- Детализация сборки (CLOUD-DETAIL-r172): detail-preset xbin (edge/sky/balance off, step=1, без среза
  maxPoints) + CLI tools/xbin-detail-build.js; наш фасад 589.9M плотнее Lixel в 2.3 раза, поверхности
  в 4 раза тоньше; потеря кромок из-за edge-фильтра ~11 % — лечится detail-preset + щадящая чистка.
- Толщина/плотность: в кропе 20×12 м наш файл 38 367 т/м² против 16 849 у Lixel; MAD толщины 1.48 мм
  против 5.93 мм; цветовой шум перекраса 52.7 против ~8.7 (зерно цвета — ограничение, см. CLOUD-DETAIL).
