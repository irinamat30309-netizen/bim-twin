# UI-CLEANUP-r178 — убрать лишние панели редизайна r145, убрать «false» из 3D

Дата: 2026-11-20. Изменения **не коммитил**. Скриншоты: `D:\BIM-TWIN-TEST\r55\ui-r178\`.

## 1. Источник надписи «false» в центре 3D

В реальном приложении нашёл DOM-элемент:
`<svg><text class="lx-dimtxt" x="966" y="653.75">false</text></svg>` —
это надпись размера/текста чертежа из `lixel-draw.js` (SVG-оверлей `Draw2D`), в которую из сохранённой/импортированной сущности чертежа попало значение `false` (булево/строка) вместо подписи. Такая запись оставалась в проекте/сессии и рисовалась поверх облака как плавающая надпись.

Исправлено:
- в `renderer/lixel-draw.js` добавлен `safeDimText(v)` — `false/true/undefined/null/NaN` (и их строки) превращаются в пустую строку; применяется в `mkText`, при отрисовке `text`/`dim` и **при загрузке сущностей чертежа в проект** (старые сохранённые «false» санитизируются);
- в `renderer/draw2d.js` — `safeTextOut(v)` при экспорте DXF/сущностей, чтобы «false» больше не сохранялось/экспортировалось.

## 2. Убраны элементы редизайна r145 (по умолчанию)

В `renderer/app.js` добавлен гейт `extraUiWanted()`: вспомогательные слои r145+ **не загружаются по умолчанию** (рабочее пространство — только 3D-облако + лента вкладок/меню, как до r145):
- левая вертикальная рейка и правая панель «Управление данными» + «Свойства» (`lx-redesign145.js`) — не грузятся;
- нижняя полоса «Пакетная обработка проекта / Совместить облака / Классификация / Отчёт о точности / Система координат / Mesh-инструменты / Clipping Box» и панели сечений/clipping (`p1-tools.js`, `sections-p2.js`, `clip-p3.js`) — не грузятся;
- панель/пилюля «Производительность» (`perf-panel.js`) — не грузится.

Опциональное включение (если нужно вернуть):
`window.__bimEnableExtraUi()` (ставит `localStorage['bim.extraUi']='1'` и перезагружает окно);
`window.__bimDisableExtraUi()` — обратно. Сами функции/файлы слоёв сохранены, r130 (лента, светлая тема с тёмным 3D, привязка off) не тронут.
