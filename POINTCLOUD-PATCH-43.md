# POINTCLOUD-PATCH-43 (v1010)

Правки по 4 пунктам пользователя.

## 1) Установщик Open3D/SciPy не открывался
- main.js `bim:installPyDeps` (Windows): раньше `Start-Process powershell` из скрытого
  рендерера часто не показывал окно.
- Теперь генерируется `bimtwin-install-pydeps.bat` в %TEMP% и открывается через
  `shell.openPath` (в новом видимом окне cmd), fallback `cmd /c`.
- В .bat: определение py/python, проверка версии, предупреждение про Python 3.9-3.12,
  `pip install --upgrade numpy scipy open3d`, статус, pause.

## 2) Очистка удаляла ~3к точек, разницы не видно
- app.js vtClean: denoise `minPts 8 -> 12`, `factor 2.2 -> 1.8`.
  Меньший воксель + выше порог соседей = агрессивнее к «пыли»/висящим точкам,
  плотные поверхности сохраняются.

## 3) Парсер плотности модели (LAS/PLY) + «подстройка точек»
- webgl-viewer.js: новый `_estimateSpacing(pos,n)` — берёт непрерывные срезы точек
  (в файле идут по порядку сканирования), строит хеш-сетку и считает медианный шаг
  до ближайшего соседа = реальный межточечный интервал модели.
- Считается ДО shuffle (иначе порядок теряется). Используется как `_spacing`.
- Лог в консоль: точек, габариты X×Y×Z м, реальный шаг в мм.
- Все точки модели уже загружаются (единый буфер, порог LOD = Infinity) —
  теперь размер сплэта = реальной плотности, поэтому поверхность без пустот.

## 4) Резкость: убрать крупные размытые кружки
- РЕГРЕССИЯ v1009 исправлена: профиль «Максимум» больше НЕ включает круглые
  сплэты и не раздувает размер. Теперь «Максимум» = квадратные точки + перспективный
  размер + EDL (резко, как в CloudCompare).
- Перспективный размер (`_attenuate`) включён по умолчанию при загрузке облака:
  поверхность сплошная вблизи, точки мельчают вдали — уходит «ковёр из кружков».
- Множитель сплэта `2.4 -> 1.8` (визуальный и pick-проход) — плотно, но без слипания
  в «объём».
- Тонкие элементы (рамы) с точным шагом и квадратными точками читаются резче.
