  потокового буфера (sample), ассистент больше не пишет ложно «Откройте облако точек».
- Плавающая подпись привязки убрана: подсказка «Привязка: плоскость · шум…» выводится в углу
  статуса #lxInfo, а не бегает за курсором (.meas-snap-tip больше не создаётся).

- ИИ-контекст (renderer/ai-context.js): структурированный ai-context/1 — облако, выделение,
  распознанный элемент, инспектор, измерения, модель, проект, документы; факты только из приложения.
- ИИ-намерения (renderer/ai-intent.js): локальный парсер рус/укр фраз без модели — «что это за
  элемент», «это стена?/труба?», «какая толщина», «сколько площадь», «найди двери», «сверь с
  документацией», «посчитай…», «что в модели»; при отсутствии данных — честное «Не знаю».
- «Что это?» по классификатору элемента: щелчок по облаку → ElementIdentify + auto-measure,
  карточка с типом/размерами/нормоконтролем; модель (если готова) дополняет объяснение по фактам.
- Авто-измерения: обновлённый auto-measure (212 КБ) — стабильные типы/размеры, «Измерить заново»,
  «Указать объект», уровни/допуски; 48/48 фраз контекста (тесты r169-ai-context/r169-ai-intent/
  r169-inspector-ui/auto-measure-r169).
