# План r119: документация + ИИ-помощник + тесты фасада

Цель заказчика: перед построением BIM можно загрузить проектную документацию (PDF/ZIP), система
извлекает размеры, сравнивает с облаком и моделью и подсказывает, как довести модель до идеала;
плюс прогнать тесты фасадов/окон и сверить размеры облака с документацией.

## Блок 1. Фасад и окна — автотесты (phase2-facade)

| Шаг | Что | Критерий |
|---|---|---|
| 1.1 | Тест-скрипт `facade-test.py`: прогон `scan2bim_facade.py` на map-120 и map-window с проверкой этажей/шага/окон | recall ≥95 %, шаг 3.70/3.69, число окон = эталону |
| 1.2 | Сверка с документацией: отметки этажей +0.000/+3.700/+7.400, шаг **3.700 м** | расхождение ≤10 мм |

## Блок 2. Извлечение документации и сравнение (phase5-regression)

| Шаг | Что | Критерий |
|---|---|---|
| 2.1 | `docs-extract.py`: PDF/ZIP → JSON (помещения с площадями, габариты в осях, толщины стен, ширины дверей, отметки этажей) | работает на реальных PDF заказчика (245+ стр.), кодировка UTF-8, без интерактива |
| 2.2 | `docs-compare.py`: JSON документации + модель + облако → таблица «проект ↔ модель ↔ облако» с Δмм/%, скор соответствия 0–100, список рекомендаций | пороги A1–A8 + инженерные размеры; честные SKIP при отсутствии данных |
| 2.3 | CLI одной командой: `python docs-compare.py --docs report.json --model py2-final-v4.json --cloud koridor-local-rgb.bin --out compare.json` | код 0 при успехе, JSON схемы |
